# 方案设计：薪资与技能强关联分析

## 1. 核心链路设计
1. **数据提取 (`csv_parser.py`)**: 
   增加 `get_salary_column` 和 `get_salaries` 方法，自动识别 '薪资', 'salary', '月薪' 等列，返回与 `descriptions` 一一对齐的字符串列表。
2. **薪资标准化提取 (`salary_analyzer.py` - 新增)**:
   提供方法 `parse_annual_salary(text: str) -> Optional[float]`。
   - **规则1**: 处理 `15-25K` -> 取平均 20K -> 240,000
   - **规则2**: 处理 `20-30k·14薪` -> 取平均 25K * 14 = 350,000
   - **规则3**: 处理 `300-400元/天` -> 平均 350 * 22 * 12 = 92,400
   - **规则4**: 处理 `1.5万-2万` -> 175,000
3. **统计计算 (`app.py`)**:
   - 在主分析循环（包括 Jieba 和 混合模式）中，遍历 `descriptions` 时同级遍历 `salaries`。
   - 维护一个全局结构：`skill_salaries = defaultdict(list)`，记录每个技能出现时该岗位的薪资数值。
   - 计算完成后，聚合成 `skill_avg_salary = {skill: sum(salaries)/len(salaries)}`。
4. **结果输出**:
   - **后端 API**: 返回的 `top_skills` 新增 `avg_salary` 字段。
   - **Excel 生成 (`excel_generator.py`)**: 
     - 在「总计总表」中新增一列【平均年薪】。
     - 增加一个全新的 Sheet:【🔥 高薪技能挖掘】，按平均年薪降序排列（设定阈值：样本数 >= 3 才参与排名，避免个例干扰）。
   - **Web UI (`index.html`)**: 在结果面板中，对于 Top 技能展示其薪资范围。

## 2. 优势分析
- **极其轻量**：纯正则运算，时间复杂度 O(N)。
- **高业务价值**：给用户提供真实的“溢价技能”指引，极大提升产品调性。

## 3. 边界情况处理
- 薪资列缺失：如果在 CSV 中找不到薪资列，直接跳过此项分析。
- “面议”等无法解析的薪资：返回 `None`，不计入平均值计算。
