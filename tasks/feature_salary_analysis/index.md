## 📝 关键决策
- **统一度量衡**：所有解析出的薪资最终全部统一折算为【万/年】，以便于跨度比较。
- **样本约束**：计算排名时，过滤掉出现次数过少（如频次 < 3 次）的技能，防止个别特例扰乱"高薪榜单"。

## 🚨 风险与问题
- **正则覆盖率**：薪资格式千奇百怪，第一版正则可能无法 100% 覆盖，对无法识别的按 `None` 丢弃，不强求。
- **已修复 Bug**：`w_year` 正则 `/年` 后缀为 optional 导致抢先匹配月薪格式，已改为必须含 `/年`。
