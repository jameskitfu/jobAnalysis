# 调研报告：前端与 AI 技能词库扩充

## 1. 前端技术栈核心词汇（2024-2025 趋势）
基于 Web 搜索结果，前端领域已从简单的 HTML/CSS/JS 演进为涵盖编译、渲染、移动跨端、GIS、低代码及 AI 辅助开发的复杂生态。

### 关键维度：
- **基础与语言**：HTML5, CSS3, ES2024, TypeScript 5.x, WebAssembly (Wasm).
- **主流框架**：React 19, Vue 3.5, Angular 19, Svelte 5.
- **同构/Meta 框架**：Next.js, Nuxt.js, Remix, Astro 4.
- **样式方案**：Tailwind CSS, Shadcn UI, UnoCSS, CSS-in-JS.
- **构建工程**：Vite 6, Webpack 5, Turbopack, Rspack, Monorepo (pnpm).
- **跨端/移动**：React Native, Flutter, Electron, Uni-app, HarmonyOS (ArkTS).
- **可视化/3D**：Three.js, ECharts, D3.js, WebGPU, Cesium, AntV.

## 2. AI/大模型技术栈核心词汇
AI 领域重点已从传统机器学习转向生成式 AI (GenAI) 和智能体 (Agents)。

### 关键维度：
- **算法/理论**：Transformer, Diffusion, GAN, RLHF, 思维链 (CoT).
- **大语言模型 (LLM)**：GPT-4o, Claude 3.5, Llama 3.1, Qwen 2, DeepSeek-V2.
- **应用模式**：RAG (检索增强生成), Agentic Workflow, Prompt Engineering, 函数调用 (Function Calling).
- **框架与工具**：LangChain, LlamaIndex, PyTorch, TensorFlow, Hugging Face.
- **工程化 (AI Ops)**：MLOps, LLMOps, 向量数据库 (Pinecone, Milvus), 模型微调 (LoRA, QLoRA), 模型量化 (GGUF).
- **AI 编程**：Copilot, Cursor, Codeium, AI 辅助重构.

## 3. 词库扩充策略
- **深度拓展**：不仅包含技术名，还包含版本、核心概念（如 Hooks, Signals）、周边生态库。
- **中英双语**：确保如“虚拟 DOM”和“Virtual DOM”都能被识别。
- **去重与规范**：统一大小写（如 React.js vs reactjs），避免 Jieba 匹配冲突。

## 4. 预期规模
- 前端部分：预计新增 800+ 核心词汇及变体。
- AI 部分：预计新增 600+ 核心词汇及变体。
- 综合其他相关 IT 基础：200+。
